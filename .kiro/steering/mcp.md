# MCP

Unity and Blender MCP servers may be connected on a developer machine. They were not available in the sandbox that built this repo, so no MCP tool has been used and no result may be described as MCP-verified. Prompts live in docs/MCP.md. Config goes in a local `.kiro/settings/mcp.json` (placeholders only, no secrets, not committed with live commands). Never commit pack-derived content produced through Unity or Blender sessions. `tests/UnityCompileCheck` is a stub-based check and is not a substitute for compiling in Unity. See `project.md` (Verification Before Claims) and `agent.md` (three-tier labels). Unity cannot be installed in the sandbox because Personal licence activation is tied to the author's Unity account; prompts 6 to 12 in docs/MCP.md are for the author's machine.
