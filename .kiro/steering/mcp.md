# MCP

Unity and Blender MCP servers may be connected on a developer machine. They were not available in the sandbox that built this repo, so no MCP tool has been used and no result may be described as MCP-verified. Prompts live in docs/MCP.md. Config goes in a local `.kiro/settings/mcp.json` (placeholders only, no secrets, not committed with live commands). Never commit pack-derived content produced through Unity or Blender sessions. `tests/UnityCompileCheck` is a stub-based check and is not a substitute for compiling in Unity.
