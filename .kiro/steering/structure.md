# Structure

See `project.md` for the Core, Runtime and Web responsibilities; this file lists the layout.

```
.kiro/                 specs, hooks, steering (always committed, never ignored)
Packages/com.michaelinzo.frankenstein-village/Core    pure C# logic (testable without Unity)
Packages/com.michaelinzo.frankenstein-village/Runtime Unity glue (MonoBehaviour, ScriptableObject)
Packages/com.michaelinzo.frankenstein-village/Editor  editor-only tools (CatalogAutoBinder), unverified in Unity
Packages/com.michaelinzo.frankenstein-village/Data  catalog JSON describing stitchable pieces
Packages/com.michaelinzo.frankenstein-village/package.json, Samples~   UPM package manifest and sample; Runtime also holds the playable layer (FirstPersonExplorer, InteractionRaycaster, DreadHud), Editor holds PlayableVillageSceneBuilder
tools/gen_package_meta.py   writes and checks the package .meta files
docs/UNITY_SETUP.md    install and play steps for HDRP and URP
Assets/ThirdParty      placeholder only; paid packs are gitignored
Packages/ ProjectSettings/   Unity project config
web/                   browser demo: JS port of Core + canvas UI (static; host configs in netlify.toml, vercel.json, web/_headers; see docs/HOSTING.md)
tests/                 dotnet xunit property tests over Core, plus golden parity file for web/
tools/validate_repo.py repo guardrails
docs/                  Kiro usage, demo script, Devpost draft
docs/media/            screenshots used by the README (each under 1 MB)
tools/fetch_pack.py, inspect_unitypackage.py, build_local_pack.py   local pack tooling (output git-ignored)
web/src/building.js    pure helpers for themes, floors, doors, camera, detail (node tested; policy itself is in core.js)
web/src/stitch.js, codex.js, achievements.js, daily.js, access.js, progress-ui.js   round 10 panels: pure logic tested in web/test; progress-ui.js owns the DOM
web/src/progress-gate.js, journal.js, tour.js, tour-ui.js   round 11: arming gate, Story and Progress tabs, judge tour (pure logic tested; tour-ui.js owns the DOM)
web/src/view3d-math.js, view3d.js   round 14 opt-in first-person WebGL view: pure camera, picking, fog, sky and lantern maths (web/test/view3d.test.js) and the GL/input shell; rules come from InteractionRules in core.js, meshes from glb.js
web/src/scene.js       pure scene helpers plus round 13 notice pacing (seeded lightning and shake, flash gate, banner coalescing; web/test/notice-policy.test.js)
web/data/stitch.json   generated by tools/gen_stitch.py (never hand edit; validator checks it)
web/local-pack/        ignored output of build_local_pack.py for ?pack=1 (never commit; no pack screenshots in docs/media)
Assets/_DLNK/          Unity import location of the real packages (ignored)
tools/screenshot.sh    renders the web demo to docs/media with headless Chromium
```

Rules: new logic goes in Core first with a property test; new MonoBehaviours only wrap Core. If you change Core behavior, regenerate the parity contract with `UPDATE_GOLDEN=1 dotnet test tests/Frankenstein.Core.Tests` and update `web/src/core.js`; `web/data/village_catalog.json` must stay identical to `Packages/com.michaelinzo.frankenstein-village/Data/village_catalog.json`. Never add files under `Assets/Lovecraftian Village*`, `Assets/_DLNK` or `web/local-pack`.
tools/stage_web.py     stages web/ into git-ignored dist/ without local-pack (only safe local-folder deploy)
tests/UnityCompileCheck  stub-based compile check of Runtime and Editor scripts (dotnet build; syntax and types only, see docs/MCP.md for Unity/Blender MCP prompts)
tools/dlnk_scene.py, tools/blender/   scene layout parser and headless Blender scripts
tests/UnityCompileCheck   stub-based compile check
web/assets/meshes/   original GLB meshes (only .glb allowed here); web/meshes.html viewer
web/src/title.js, title-ui.js   round 17 title screen (pure decision plus DOM); web/src/vigil-ui.js, vigil-view.js   Vigil objective, ending dialog and result card (pure view models plus DOM)
Packages/com.michaelinzo.frankenstein-village/Core/VillageVigil.cs   Vigil rules (Core, mirrored in web/src/core.js)
web/assets/og-preview.png   1200x630 share image (3D render; see CHANGELOG for the command)
