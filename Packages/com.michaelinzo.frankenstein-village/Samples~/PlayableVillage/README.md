# Playable Village sample

1. Import this sample from Package Manager (Frankenstein's Lovecraftian Village > Samples).
2. Run **Tools > Frankenstein > Create Playable Village Scene**.
3. Press Play. WASD move, mouse look, E interact, V cycle camera (first person, third person, top down).

The builder uses prefabs from the DLNK Lovecraftian Village pack when you have imported it and bound the
catalog; otherwise it falls back to primitives. The pack is not included. See docs/UNITY_SETUP.md.

Status: Unity runtime behavior is Unverified (never executed in Unity from this repository).
