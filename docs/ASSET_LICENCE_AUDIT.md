# Asset licence audit (round 25)

Audit of itch.io pages for possible future villagers, houses, props and sound. Source: the licence field and description of each page, read on the audit date. **Nothing was downloaded or committed.** A page is only a claim by its author; before any file is committed, re-read the licence on the download itself and record it in `THIRD_PARTY_ASSETS.md`.

Policy: only **CC0** or **CC-BY** (with credit in `THIRD_PARTY_ASSETS.md`) may be committed. Anything non-commercial, no-redistribution, "do not re-upload", personal-use-only, no-derivatives or without a stated licence is skipped, because this repository is public and redistributes the files.

Decisions: **use** (CC0 or CC-BY, eligible), **skip** (licence not compatible), **unclear** (no licence stated, ask the author or leave out).

## Before adding any file
1. Download from the author's own page and read the licence inside the archive.
2. Add the file, source URL, author, licence and any required credit to `THIRD_PARTY_ASSETS.md` (`python3 tools/validate_repo.py` fails on an unlisted file under `web/assets/third_party/`).
3. Keep each runtime mesh small (the project budget is 200 KB per mesh) and keep the original Blender meshes as the default.
