        Keyboard
        • W whisper
        • C enter the church
        • L light a candle
        • N new village
        • [ ] sanity -5 / +5
        • D let the dark creep in
        • M music on/off, U mute
        • S story mode; while open , . or Left Right step beats, Space play/pause, Esc exit
        • , . previous / next night
        • P save postcard
        • G village map and legend
        • I send an investigator along the lantern route (also ?investigator=1)
        • B cinematic capture mode: chrome hidden, scripted camera through this night's story beats (also ?cinematic=1)
        • Gamepad: stick or d-pad pick a landmark, A listen, B door, X whisper, Y candle, Start story, Select cinematic. Touch: swipe sideways to pick a landmark, up for a candle, down for a whisper.
        • K codex and achievements (also ?codex=1)
        • Y how the parts are stitched together (also ?stitch=1)
        • H high-contrast theme (also ?contrast=1)
        • Z today's village, the same seed for everyone on this date (also ?daily=1)
        • A about and credits (Esc closes)
        • Guided tour of the features, about a minute, only when you ask for it with ?tour=1
        • X performance readout (also ?perf=1)
        • T next texture theme
        • V next camera (first, third, top-down, auto)
        • F peel up one floor (top-down only)
        • O try the next door
        • ? show or hide this list
        • View focused: Left Right pick a landmark, Enter listen

        Same Core logic as the Unity 6 HDRP project (source), ported to dependency-free JS and checked against C# output. The Unity build uses the DLNK Artworks Lovecraftian Village pack; this page uses only procedural shapes and an original procedural soundtrack (no audio files, off until you opt in). Add ?intro=0 to skip the intro, or ?lang=fr for the French strings. Apache-2.0. Run the parity self-test.

        About and credits

        Browser demo of the Frankenstein's Lovecraftian Village Unity 6 project, built for Kiroween 2026. The Unity build uses the Lovecraftian Village 1.3 HDRP pack by DLNK Artworks. That pack is a commercial asset owned by the author of this project and is not in this repository or on this page; this demo uses only procedural shapes and an original procedural soundtrack.
