        Frankenstein's Lovecraftian Village

        A procedural cosmic-horror village. Change the seed, lose your sanity.

        Procedural music, no audio files. Nothing plays until you switch this on.

        Enter begins. Escape opens the map view.

        How to play

        Gamepad: stick or d-pad pick a landmark, A listen, B door, X whisper, Y candle, Start story, Select cinematic.

        Touch: swipe sideways to pick a landmark, up for a candle, down for a whisper. In 3D, drag the left side to walk and the right side to look.

        Play

        • W whisper
        • C enter the church
        • L light the next lantern
        • E endure the night once enough clues are heard (2D view)
        • N new village
        • [ ] sanity -5 / +5
        • D let the dark creep in
        • , . previous / next night
        • O try the next door
        • S story mode; while open , . or Left Right step beats, Space play/pause, Esc exit
        • View focused: Left Right pick a landmark, Enter listen

        View

        • V next camera (first, third, top-down, auto)
        • T next texture theme
        • F peel up one floor (top-down only)
        • G village map and legend
        • P save postcard
        • B cinematic capture mode: chrome hidden, scripted camera through this night's story beats (also ?cinematic=1)
        • I send an investigator along the lantern route (also ?investigator=1)

        Audio

        • M music on/off, U mute

        Accessibility

        • H high-contrast theme (also ?contrast=1)

        Tools

        • K codex and achievements (also ?codex=1)
        • Y how the parts are stitched together (also ?stitch=1)
        • Z today's village, the same seed for everyone on this date (also ?daily=1)
        • A about and credits (Esc closes)
        • Guided tour of the features, about a minute, only when you ask for it with ?tour=1
        • X performance readout (also ?perf=1)
        • ? open this help

        About and credits

        Browser demo of the Frankenstein's Lovecraftian Village Unity 6 project, built for Kiroween 2026. The Unity build uses the Lovecraftian Village 1.3 HDRP pack by DLNK Artworks. That pack is a commercial asset owned by the author of this project and is not in this repository or on this page; this demo uses only procedural shapes and an original procedural soundtrack. Code is released under the Apache License 2.0: read LICENSE and NOTICE.

        Also see the original Blender meshes: thirteen low-poly models made for this project, drawn by a small software projector.

        Enter, Space or Right arrow for the next stop, Left arrow to go back, Escape to skip.
